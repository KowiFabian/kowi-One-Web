# KOWI News y Communications
/news reúne un radar de lanzamientos estables de los últimos 90 días y lecturas editoriales con datos observados, interpretación y recomendación. Fuentes oficiales verificadas el 2026-10-04: OpenAI SDK Python 3.24.0 (2026-10-02), NVIDIA OpenShell 0.1.2 (2026-09-28), Supabase JS 2.117.1 (2026-09-23).

## Actualización y límites
Se consultan tres repositorios oficiales, sin credenciales, con timeout y caché Next de una hora. La página ISR se regenera al recibir una visita después de ese intervalo; no es un crawler en segundo plano. Se excluyen drafts, previews, URLs ajenas y fechas futuras o anteriores a 90 días. Si falla una fuente se informa y no se inventan titulares. No se ingiere Markdown ni se envían datos empresariales al radar.
Las lecturas editoriales iniciales fueron revisadas en esta ejecución autorizada. Nuevos artículos y resúmenes AI deben prepararse, verificar fuentes y obtener aval del contenido exacto; no existe publicación autónoma de IA.

## Comunicaciones corporativas
Perfil de agente KOWI Communications y área communications del director: contraste de fuentes; mensaje y audiencia; separación hechos/interpretación; marca y privacidad; autorización de contenido/canal; medición observada.
La orden genera seis tareas internas, únicamente tras aval del Company Owner verificado, con límites y ledger existentes. No publica ni envía emails; seleccionar el perfil no activa un proceso de IA. La IA empresarial privada puede preparar borradores cuando esté validada.
La expansión de fuentes, editor CMS, publicación editorial con aprobación vinculada al contenido y conectores sociales están pendientes. No prometer campañas activas o métricas de atención sin evidencia.

## Estilo Human-First
Lenguaje comprensible, cálido y preciso. La comunicación explica posibilidades, límites y decisiones; evita amenazas de desempleo inevitable, catastrofismo y urgencia artificial. No utilizar datos personales para captar atención sin finalidad y autorización. Invitaciones a la comunidad deben ser voluntarias.

## Verificación
Test de rango temporal, origen, previews y malformed input. Test SQL del plan communications confirma seis tareas, aval, idempotencia y external_execution=false. Browser Desktop/Pixel verifica fuentes y navegación News; producción comprueba /news. Estas pruebas no acreditan un agente de IA editorial activo.
